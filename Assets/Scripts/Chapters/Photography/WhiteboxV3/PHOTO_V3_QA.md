# 摄影白盒 V3 接口与通关验证

命名空间 `MemoryWhitebox.V3`。原版摄影脚本未修改。

## 主循环接口

- `new PhotoChapter()`；`new PhotoWorld3D(host, model)`，主机依次调用 `Activate / Tick / ApplyPose / PointerRay / Pick / Press / Move / Release / Scroll / DrawOverlay`。
- `WantsMouseLook=true` 使用锁定鼠标，内部将 `WBInput.PointerDelta` 累加为 1280×760 的虚拟指针。`DrawOverlay` 画虚拟小光点；不会出现桌面边界阻止转身。
- `PhotoWorld3D.CompletionImages` 在整卷三张相纸洗好晾干后返回三张真实快门画面。纹理在完成通知回调前创建。源快门纹理 `ShotTextures` 和曝光参数副本 `PhotoChapter.Exposures` 始终保留。
- `PhotoV3Checks.Run()` 成功返回检查描述，失败抛出 `InvalidOperationException`。可设 `PhotoV3Checks.CaptureStage = (name, world) => ...` 接收真实 3D 渲染阶段。校验本身不另开 Unity。
- 世界 QA 接口：`QAEnter(Inspection)`、`QASetActor(localEye, yaw)`、`QAEdge(logicalPointer)`、`QAShoot()`、`QARayTo(id)`；`PhotoV3Checks.Align(model)` 只供自动化快速对准。

## 人工通关

1. 公园内 WASD 行走、鼠标环视。停稳后将小光点移至左下角，停留约 0.24 秒看测光表；移至上沿退出。右下角进入机身。进入角落仪器时恢复手势前最后停稳的构图。按住右键可连续环视并将小光点收回中央。
2. 点击机身左侧后盖闩。拖一枚 100／200／400／800 胶卷入左侧暗色片仓；拖片头到右侧收片轴；点击浅色齿孔压条；点击过片杆检查；点击翻开的后盖关闭；再点击过片杆准备第一张。操作取消会返回原位置，已完成步骤保留。
3. 点击取景器进入。中心滚轮调合焦距离，焦距固定 50mm。左沿进入光圈小窗、右沿进入右肩快门旋钮；对应视图内滚轮只改当前参数，移回中央返回取景器，上沿返回公园。测光表给同一测光 EV 下 1/125 秒的光圈；允许换算其他等值组合。
4. 对齐左上角同场景预摄的照片。取景器裂像对齐表示合焦；右下原生指示灯亮起后，女孩才开始动。第 1 张转头／发丝角度改变，第 2 张转肩，第 3 张伸手；第 3 张先点一次回应伸手，再点一次快门。没有文字提示或即时成片预览。
5. 每次快门后回到机身，点击过片杆，移上沿回到公园寻找下一张角度。三处构图中心沿公园通路分别约 X=0、8、16 米；参考视点 Z≈0，人物在前方约 5 米。验收用 ISO100 可依次用 f/8、f/5.6、f/4 + 1/125 秒，合焦距离约 5.0、5.2、4.8 米。
6. 三张后，按住倒片钮滚轮回卷，自动转到暗房。拖左前方胶卷入暗袋，点击袋口拉链；按住袋中圆形片轴滚轮装片，再点击显影罐盖封罐。
7. 按瓶身圆点顺序，将药瓶拖到罐顶注液口：显影液 → 点击排液槽 → 停显液 → 排液 → 定影液 → 排液 → 点击水龙头清洗 → 排液。显影、定影需按住罐体晃动一下才继续计时。未定影清洗前，开罐被拦截；错误药液不会丢进度。
8. 点击罐盖打开，拖底片到后方晾绳；晾干后拖到右后接触印相框。按住上方印相灯完成曝光，提前松开只重试这一步。依次将相纸拖到 1／2／3／清水四只托盘，每次等待局部处理完成，再拖下一盘；最后拖到晾绳晾干，三张成片回填照片墙。

## 白盒边界

公园、邻居房屋、桥、秋千、女孩、器械、手和暗房均为可编辑 3D 基础体。脸部由高亮面片与背光遮挡，没有面部五官。光学合焦采用取景器裂像反馈及景深计算，未加入成品级镜头虚化和角色动画。暗房时间压缩至秒，整卷三张合并为一次接触印相流程；曝光参数和实际快门纹理仍分别冻结。
