# 《留在手边的事》完整流程白盒 v3

目标是验证完整的五天游戏循环与操作负担。场景、人物、手部和音频使用可替换的几何或程序占位；该版本不是美术成品。

## 打开与构建

使用 **Unity 2022.3.62f3** 打开仓库根目录。首次打开按仓库现有 `Packages/manifest.json` 解析依赖。

1. 打开 `Assets/Scenes/WhiteboxV3.unity`，或菜单 `Tools → Whitebox V3 → Open Five Day Demo`。
2. 按 Play，从春季卧室开始。默认没有任务文字、字幕和按键提示；器械数字保留。
3. 菜单 `Tools → Whitebox V3 → Build Windows Demo` 会先执行规则检查，再生成 `Build/WhiteboxV3/MemoryWhiteboxV3.exe`。

也可在项目根目录运行：

```powershell
.\BuildWhiteboxV3.ps1
# 仅运行规则检查
.\BuildWhiteboxV3.ps1 -ValidateOnly
```

Windows运行包须整体保留 exe、Data、MonoBleedingEdge及DLL。源代码仓库不提交Unity Library与构建缓存。现有 HouseScene/ParkScene 的入口与构建脚本不受本版本影响。

## 一局流程

一句话循环：**在四季卧室发现物件 → 用媒介的具体操作重建一段记忆 → 带回物件的变化 → 进入下一天。**

3C：第一人称成年人；WASD/鼠标探索，进入媒介后按该媒介分配双手操作；卧室第一人称、物品检视特写、写作分屏和固定位置绘画四种镜头受场景状态控制。

| 天数 | 进入物件 | 通关条件 | 回屋变化 |
|---|---|---|---|
| 春 | 书桌双卡座/磁带盒 | 连续完成2盘音乐与1盘叙事录音，主动跳过杂音 | 夏日强光、薄被与衣物变化 |
| 夏 | 床侧照片墙 | 三处复刻构图、实际曝光、完整冲洗出三张照片 | 照片回挂墙面，进入秋季 |
| 秋 | 中央茶几纸笔 | 同时写字与操控回忆，在60秒内收齐四件物品到玄关并告别 | 冬季积雪与厚被 |
| 冬 | 床与衣架之间的画板 | 秋千/桥、行李/花轮/吊坠门、直线路径与鼻部截断 | 回到融雪开花的春天 |
| 春回 | 身后发光房门 | 开门并亲自跨过门槛 | 纯白结束 |

## 操作

卧室：WASD行走，鼠标环视；靠近并对准当前轻微发光的物件，左键或E进入。Esc返回卧室，关卡本次运行内状态保留。只有本日物件能触发正常流程。

### 春：磁带

- 从收纳盒中拿起候选磁带。按住实际左轮轴或右轮轴，再滚轮检查；两边从中部检查到端点，完整覆盖整段才算检验。红色断头意味着换带。
- 在桌上胶带座拉出足够长度并撕下，分别贴住磁带上方两个防覆写孔。准备好的空带装右卡座B，委托原带装左卡座A。
- A使用机身图形按钮独立播放/停止/倒带/快进。B的五个键从左到右：**S录音、F播放、J倒带、L快进、'停止**，按住才保持。
- S+F录入实际PCM。杂音出现前停下B，A继续播放；杂音结束后重新S+F续录。松开S但保持F会让B继续走带，留下空段，不能当成暂停。
- STOP优先，需要松开再重新按F才能继续。可倒带试听B的实际录音。把完成的B拖到交付位置验收；失败重录当前盘，成功盘保留。

### 夏：摄影

- 左上角是本次参考照片。WASD找位、鼠标环视；可按住右键持续环视并收回虚拟光标。
- 虚拟光标移到左下角并稍停读取测光表，顶边返回；右下角进入相机本体。边缘切换有停留与重新回中要求，防止连跳。
- 选择100/200/400/800 ISO胶卷，打开后盖、放入暗盒、拖出片头、卡入片轴齿孔、检查过片、关闭后盖、过片就绪。
- 点击取景器。镜头固定50mm，中心滚轮调**对焦距离**；左边缘进入光圈小窗调光圈，右边缘到右肩旋钮调快门，移回中央返回取景，顶边放下相机。
- 参考构图与曝光/合焦达标后，女孩开始轻微回头或伸手，构图资格不会因这个动作被撤销。第三张需要回应伸手。点击快门后冻结实际三维画面，不即时预览。三张之间手动过片。
- 倒片、暗袋绕片与封罐后，按器具形状及液体颜色处理：显影→排液→停显→排液→定影→排液→水洗→晾干→接触印相与相纸处理。摇动/等待钟针是实际门槛。成片处理实际快门纹理；三张完成后挂回卧室。

### 秋：写作

- **左侧真实纸面：右手按住鼠标并移动运笔；右侧三维回忆：左手WASD移动、E拾取/告别。** 按住鼠标不动不算书写。
- 首稿是不限时练习，拾到第一件物品后卡稿。点击纸张团起并拖入纸篓，进入正式稿。
- 正式稿第一笔开始60秒；停笔仍计时，拾取需要最近仍在写字。吊坠、花、信、行李可任意顺序收集，一次携带全部。
- 在期限内带齐四件到玄关即可锁定成功、停表。继续写字并按住E完成告别。超时也通过丢纸团重试，不触发死亡结局。

### 冬：绘画与画册

- 现实视点固定，WASD不会移动现实角色。未聚焦时风景虚焦；鼠标环视，按住左键稳定聚焦关键物件，把它加入画册。
- 下边缘抬起画册，上移放下。画册中A/D移动、Space跳跃；放下画册时角色和平台运动暂停。
- 第一幕：聚焦秋千后乘坐，A/D摆荡、Space荡过空隙；再聚焦桥，搭桥过河。
- 第二幕：行李压板开上车口；花变成可乘坐的花形风车，转到高处后跳离。现实空房里隐蔽的吊坠需从固定视点寻找，聚焦后带到画册；终点门的同形凹槽提示用途，拖拽放入才能开门。
- 两幕没有女孩。之后纸面保持可见，路径变直线；沿直线前进，病房自下而上恢复，女孩坐在病床上。揭示到鼻部阈值立即中断，完整正脸不出现。

### 春回：结局

雪融、窗台花开。转身开门，走过门槛即可结束，不增加围巾或其他道具门槛。

## 存档与调试

- 独立存档目录：`Application.persistentDataPath/WhiteboxV3`，不读取或覆盖旧摄影存档。
- 自动保存**完成的天数**与三张成片；关闭程序后未完成的当天从本关起点重来。本次运行内Esc退出保留进度。
- H打开/关闭开发帮助。仅帮助打开时，1–5跳关、R重置当前关、Ctrl+Backspace从头开始；M静音。
- `--v3-fresh` 忽略已有检查点从春天开始；正常运行仍保存新进度。
- `MemoryWhiteboxV3.exe --v3-qa-capture` 运行规则/空间验证和实际GPU截图，报告在程序目录的 `QA-V3`。QA不写玩家存档，失败退出码2。

场景遵循`docs/ProjectOrganization.md`的Systems/Player/Environment/Gameplay/Lighting分组，新增代码位于独立命名空间`MemoryWhitebox.V3`。模型与输入/镜头分离，后续可替换各章World中的占位物件而保留关卡规则。

## 当前白盒边界

使用基础网格、程序合成录音和简化手部/女孩剪影。摄影的冲洗时长经过压缩，显影是对实际曝光图像的处理，不是化学或光学的科学级模拟。写作笔迹为抽象运笔线；绘画平台、相机和磁带需要后续正式美术、动画、声音及更多玩家测试。素材密度和画面品质不以本次白盒冒充《艾迪芬奇的记忆》成品。

具体实际运行结果与剩余问题见`VALIDATION.md`。
