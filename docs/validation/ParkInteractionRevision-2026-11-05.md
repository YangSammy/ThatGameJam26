# 夏季公园摄影交互调整验证

日期：2026-11-05；Unity 2022.3.62f3；现有工作区。未提交或推送。

## 实施结果

E 举/收相机；未装片进入 Body，已装片进入 Viewfinder。原 E 呼唤移至 Q，保留原任务期间禁用呼唤的规则。探索右下边缘不再举相机，左下测光仍保留。光圈/快门仍由取景器左右边缘进入。

门槛源码和 ParkScene 序列化同时更新为 1m / 10° / ±1EV / .35s，对焦继续与渲染共用清晰范围。

反馈：参考图人物附近的图像边缘渐显（非精确人物分割），构图四角、中央合焦分裂标记、底部有正负方向的曝光刻度各自工作。人物回应后轮廓淡出；就绪音一次触发，2s 冷却；本帧滚轮修改后重新判定。仅 OnGUI 绘制辅助，不调用成片显示或把 UI 绘入 Camera.Render 底片。

牵手：保持锁定鼠标，中心对准掌心点击；世界 .12m 半径投影，短边百分比限幅；掌心外环与命中共用投影半径，命中时增加内环。保存 handJoined 后有 .45s 快门阻断，角色既有 .4s 握手插值负责接触演出。原来“点击牵手不耗片、后续另按快门”的存档分支保留。仅掌心悬停时抑制边缘，仍能离开掌心调参。

## 装片原因与修复

片仓原代理 5.5×5.5×4cm，可见胶卷壳约 6.25×10.35×6.25cm，片仓中心上方 4cm 的松手射线落空。片仓接收器改为 9×14×8cm，片轴 8×14×8cm；只检测本次拖动物的合法接收器，避免其他部件遮住接收。片头拖拽代理原先被 SyncAssetInstruments 每帧跟随动画覆盖；现在持有期间保留拖拽位置，动画读取它，松开后才恢复跟随。拖拽使用相机前方固定平面，避免球面取点带来的深度变化。
