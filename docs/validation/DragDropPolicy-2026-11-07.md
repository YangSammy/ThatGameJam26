# 拖拽规则检查与修改

普通拖放：有效且可用的目标上松开左键提交；无效目标、已占用目标、UI 上松手恢复本次操作前稳定状态。右键不再取消拖拽，也不会在拖拽中触发返回。暂停、失焦、显式退出仍可执行清理。

## 检查范围

| 操作 | 结果 |
| --- | --- |
| 磁带原带进入 A、工作带进入 B、准备垫、成品仓 | 保留目标/遮挡/状态验证；无效投放复位；UI 不允许穿透到自由摆放区域。旧单机芯已装载磁带的拖出失败返回原槽位。 |
| 工作台胶带贴片 | 新增开始状态快照；无效释放恢复封孔、原散片位置、可见性和卷材用量；按实际释放点重新判断。 |
| Inspection 胶带贴片 | 无效/已占用孔位恢复开始封孔；有效孔位转移；右键事件忽略；UI 上仅左键释放可结束拖放。 |
| 公园胶卷入仓、片头入轴 | 已有目标验证与无效还原；删除经右键返回触发的取消。 |
| 卧室胶卷、暗袋装片 | 保留有效接收器检查与复位；UI 释放回滚。 |
| 暗房底片、相纸、晾晒 | 保留流程阶段/目标检查；UI 释放回滚。 |
| 秋季纸团入篓 | 已有无效复原纸张/墨迹；新增原生按下和松开位置缓存。 |
| 冬季挂坠入孔 | 已有匹配孔位提交、无效回原位；改用通用原生事件缓存，避免快速释放后鼠标移动改变结果。 |

## 保留的特殊操作

| 特例 | 保留规则 |
| --- | --- |
| 操作台自由摆放 | 磁带、已注册的胶卷/暗房物件、底片和相纸可在合法 OperationArea 松手保存新位置；区域外/阻挡/UI 上释放复位。合法桌面本身属于有效目标。 |
| 暗房倒药、排液 | 对正确接收器松开提交化学流程，工具随后回原位；工具归位不代表撤销。旧相纸倒药分支也补齐接收器验证。 |
| 回卷、暗袋、显影罐搅动及曝光按住 | 持有、移动、滚轮或时间持续推进，不属于物体放置，不撤销已经积累的进度。 |
| 公园拔回卷钮 | 达到拖动阈值提交开盖步骤，保留机械动作规则。 |
| 书写笔画 | 连续留下墨迹，松手结束笔画，保留已写内容。 |
| 磁带右键旋转、Inspection 旋转/铰链/旋钮、观察控制 | 连续调节展示姿态或数值，松手结束调节；不要求放置目标。 |
| 胶带撕取 | 保留拉出/切断动画，但未成功贴到有效孔位时，连同用量一起恢复开始状态。 |

## 验证

- Unity 2022.3.62f3 编辑模式脚本刷新/编译，无编译错误。
- 隔离 C# fixture：Inspection 贴片无效释放、有效转移、已占用目标拒绝、右键忽略、中断恢复通过；ObjectDragSession 的位置/旋转/缩放恢复通过。
- 工作台 fixture：右键旋转保留，原带及工作带拖拽忽略右键按下/释放；贴片和已有散片在无效位置释放恢复原状态及精确开始位置。
- 输入 fixture：活动手势屏蔽返回、不消耗左键操作权限、被忽略的右键不延迟漏到返回；空闲返回保留；快速原生按下/松开射线保留。
- 独立静态复核未发现阻塞问题。没有启动完整 Play Mode 或逐关人工游玩；旧单机芯恢复、所有目标的实际场景手感仍需游玩回归。
