# 摄影关卡优化实施与验收 · 2026-11-05

## 已实施

- 保存失败保留同一张待保存照片；重试先读盘确认是否已经提交，避免重复扣片。图片已写入而元数据失败时，验证同一字节后复用孤立底片。暂停菜单可重试，或明确放弃未保存照片、保留已提交进度退出。
- 元数据采用原子写入与 `.bak` 回退。恢复读取不覆盖损坏原件；后续写入保留 `.damaged`。现有胶卷不可读时不自动创建新卷替代。
- 自动跟随增加停滞检测：确实应该行进且2秒内累计不足5厘米才算卡住；先短停重试，再黑场回退路线点，持续失败提供可点击的当前拍摄点恢复。测光、暂停、拍摄点等待均不计为停滞。
- 拍摄点边缘20厘米内减弱向外移动，保留沿边移动；现有椭圆硬边界保留。到点、拍后收机继续均有提示。
- 光圈保持相机背面朝向、22°侧倾；快门18°下倾，姿态在0.2秒内平滑变化。加入清晰档位/滚轮提示；实帧复查后将光圈手部接触点移至可见左侧，避免穿过相机背板；每次实际改变档位才播放机械轻响，档位端点不会重复响。
- 装入胶卷时测光表ISO默认匹配，仍允许手动选择并明确提示不匹配；只提供曝光建议，不自动改光圈或快门。ISO100/200/400/800、EV13下分别建议f/8与1/125、1/250、1/500、1/1000秒。
- 遮挡独立于构图、合焦、曝光反馈。胸部或任一肩部可见即可；牵手掌心另判，0.3秒持续遮挡才提示，恢复0.15秒后清除，避免闪烁。忽略玩家手模型的射线遮挡。
- 参考轮廓只渲染正式角色，不提取背景树木/建筑边缘。实帧发现倒置后已修正投影方向，轮廓在参考机位与人物重合；原参考照片不改写。
- 保留入口学习、桥边观察回眸、草地主动牵手的现有表演触发；保留三处EV13及拍后收机再出发规则，不加入限时拍摄。
- PNG编码改为后台任务：主线程复制RGB像素，任务只处理托管像素，主线程非阻塞轮询并保存；失败保留同一份原始像素重试，离开/销毁后不再提交。编码/保存未完成时不允许第二次曝光或继续行进。

## 验证证据

当前Unity Editor中编译成功。独立检查输出：`output/QA/2026-11-05-Photo-Hardening/checks.txt`、`scene-checks.txt`。

- 生产异步集成：隐藏且从未激活的控制器调用真实编码→轮询→存储→成功回调，确认只提交/通知一次，保存期间阻止设置写入，退出阻止晚到提交；编码期间已收机，提交后无需重复举收机。`async-integration.txt`与`final-regression.txt`。

- 保存：写前失败、写后报告失败、孤立图片复用、同ID冲突、损坏主件/备份、双份损坏。均使用独立临时目录或内存，未重置生产存档。

- 手掌命中比例、E举收机、胶卷槽可见高度、拖动片头不被表现层覆盖、举机遮挡和取消、跟随暂停与恢复指针、软边界切向、肩部/掌心遮挡等检查通过。
- 器械与取景器用隔离暂存运行状态生成实际Game画面，完成后恢复原状态；这是实际渲染检查，并非原生鼠标全流程。图片在同QA目录的`aperture-final.png`、`shutter-final.png`、`viewfinder-final.png`。

## 性能取样

960×540真实相机离屏截图取样3次：渲染/读回5.68–8.32ms、原同步PNG编码31.32–34.33ms、文件flush2.22–5.04ms，总计39.23–45.51ms。PNG已移出主线程；优化后三次真实相机取样，主线程渲染/读回/像素复制/提交编码为5.91–6.92ms，后台完成总耗时39.21–43.81ms（不含文件存储），输出PNG约955KB。仅用于确认编码移出主线程，不能作为目标机器稳定帧率或完整快门帧时间的证明；渲染与存储仍在主线程。详见`async-profile.txt`。
