# 磁带双仓切换控制与收纳盒接入

本次以用户最后确认的规则为准：图中 2–5 控制 A，1 控制 B；数字是图中位置，不是键盘键。B 不跟随 A。此要求明确替代 v3 PDF 第 4–5 页的「五键控制 B、按住 F+S」规则。

## 当前操作

| 操作 | 键盘 / 实体控制 | 效果 |
| --- | --- | --- |
| A 播放 | F / A PLAY | 按一下播放，再按一下停止；不改变 B |
| A 倒带 | J / A REW | 按一下持续倒带，再按一下停止 |
| A 快进 | L / A FF | 按一下持续快进，再按一下停止 |
| A 停止 | 单引号 / A STOP | 停止 A；不改变 B |
| B 录音 | S / B REC | 按一下开始或续录，再按一下暂停；不改变 A |
| B 回听 | B REW、B PLAY | 先倒带，再按播放；按同键停止。停止 A 后听自己的录音 |
| 退带 | 点击对应卡槽 / EJECT | 只停止并取出该仓磁带；同一实例返回桌面 |
| 提交 | 点击打开的收纳盒后排成品格 | 沿用既有验收、PCM 保存和章节事务；保留点击关闭的成功弹窗 |
| 重试 | R，3 秒内再按 R 确认 | 清除当前委托录音，保留已准备的磁带；不重置前三份已提交成果 |
| 返回 | Esc | 近看先返回桌面；退出操作空间时停止运输并保存 |

B 录音独立运行：A 停止、倒带、快进或播到末尾时，B 若仍在录音，会记录无源信号对应的空白。玩家需要按 S 停止 B。B 暂停时写入位置保持不变，不新增同长度空白；重新录音从已有样本末尾追加，保留原有防覆盖规则。B 容量到达末端时停止。噪声区间仍只用于验收，不供普通控制器自动停录。
