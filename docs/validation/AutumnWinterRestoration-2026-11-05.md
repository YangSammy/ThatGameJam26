## 尚不能称为严格 v3 的部分

1. 按选定范围继续使用当前完整病房图片＋融雪遮罩＋实时纸面。当前图片仍是靠枕半卧姿态；遮罩上限是为该图校准的鼻高 UV，并非真实坐姿骨架鼻点。换图后必须重新校准。此轮没有把这些例外标为 v3 原案通过。
2. 秋季与冬季复用了已有纸木风格 E02 角色，源资产的动作是已有临时制作稿。接入了动作与接触处理，但不能等同最终男主角色及精修动画交付。
3. 新音乐层是明确标注的新增合成辅助层；未获得作曲原始工程/MIDI/乐器分轨。原整混未修改，原混音循环点与听感未获作曲验收；另交的 release WAV 不会在运行时自动播放。详见 `docs/Audio/AutumnWinterRestoration-2026-11-05.md`。
4. 全局无文字 UI 清理、病房坐姿图替换、真实 3D 病房不在本轮选定实施范围。原审计这些条目仍开放。
5. 编辑器通过不代表已发布构建通过；本轮未出独立安装包，也未认证跨进程完整通关、真实鼠标手感及实际听感。
