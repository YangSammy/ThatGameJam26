# 冬日纸面玩家与门的遮挡修复

用户要求玩家绘制在门前。实际纸面使用正交相机沿 route +Z 渲染，原玩家中心 Z=-0.05，门框最近表面 Z=-0.575，关门时门板挡住玩家。

修复仅在第二段纸上关卡将玩家视觉 Z 设为 -1.2。第一段、病房阶段的深度保持原逻辑；人物 XY 位置、碰撞、钥匙和穿门条件未修改。

在隔离完整项目 PhotoAcceptance-20261105 / Unity 2022.3.62f3 Play 中复现并验证：

- 修复前关门时人物中心像素是门的棕色；前移后恢复人物颜色。
- 正式修复重新编译运行，关门、开门两种状态均断言人物实际深度为 -1.2，中心像素均为人物颜色。
- 12 项叙事逻辑回归通过，包含冬日行进、钥匙、穿门和病房结束。
- 主项目文件与测试文件 SHA256 相同；未操作共享主编辑器 Play 状态。

证据位于 `output/WinterDoorDepth/`：`baseline-depth.txt`、`depth.txt`、`verified.log`、`before.png`、`after.png`。本轮没有新增独立构建。
