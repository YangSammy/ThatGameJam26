主菜单接入说明（2026-11-05）

场景：Assets/Scenes/MainMenuScene.unity，已设为 Build Settings 第一项；GameBuild 的 Windows 打包入口同步包含主菜单。HouseScene 仍负责游戏内部加载，不作为包体启动画面。之前已经生成的独立包没有自动更新，需要下次重新打包。

Hierarchy：MenuCanvas / Content 下包含 Home、Settings、Credits、Confirmation、Loading，均为场景内真实 UI，可直接调布局。MenuCanvas 上 MainMenuController 的 Credits Copy 为制作名单正文，支持多行、滚动；目前只有明确的待补名单说明，没有虚构人员。

功能：Continue / New Game / Settings / Credits / Quit。新档或不可用存档时 Continue 禁用；完整结局后提示重开。New Game 如有进度会先确认，然后把当前已知章节 JSON、录音 PCM、摄影进度及 ParkFilm 目录移入当前存档根的 ArchivedGames/时间-GUID；不删除原数据，不改存档格式。部分移动失败会回滚并留在菜单。归档不会读取为继续存档，手动恢复须在关闭游戏后把一份完整归档还原到原位置，先备份当前档。Continue 沿用 FiveDayProgress，包括现有有效 .bak 恢复机制；菜单查询本身不修改文件。

设置：总音量、转头灵敏度倍率、画质、全屏、VSync。Apply 后通过独立 PlayerPrefs 键 MemoryWhitebox.Preferences.v1 持久化；Back 不应用未确认更改；Defaults 先填入推荐值，Apply 才保存。灵敏度乘在共用 LookDelta 上，不修改场景镜头、定位或 PlayerControlSettings 资产。

游戏在 Unity 中直接打开 HouseScene Play 的开发方式保持不变。从 MainMenuScene 启动时使用正式五日顺序及正式槽文件名，但仍处于 Editor 的隔离目录。项目原有每次 Play 重置测试存档设置保持原样；开启该设置时每次 Play 菜单没有旧档是预期行为，包体不受影响。
