CHAPTER 01 / TAPE磁带 · 先检查，再录制

检查带体，保住已有的声音

玩法目标：从三盒候选带中找出可完整转动的一盒，再利用真实的持续录放操作，把 A 源带补录进 B 目标带；写入按实际时间发生，错误覆盖会留下损坏。

桌前的三盒带、中央导轨槽、后方卡座都是真实物件；两手随抓盒、握轴、压键改变位置，断点露出独立断头网格。

第一段：纯鼠标检查

输入选择候选盒；按住鼠标左键＋滚轮转左轴，按住右键＋滚轮转右轴。两轴转动和带面位移对应同一带位；不使用键盘 transport。
推理三盒中两盒有断点，一盒完整。遇断点时转动受阻，带面出现松带/断裂反馈；换盒再从头检查。不是拼接三盒磁带。
成功同一完整候选带经过从头到尾的有效检查才解锁录放；只快速反复转一小段不算完成。轮轴随带位实际旋转，带面不再出现断头。

第二段：键盘持续压住录放键

机身从左到右S / F / J / L / ' → REC / PLAY / REW / FF / STOP。按住持续生效，松开停止；不再用鼠标点亮锁存式 transport。
真实覆盖五键控制 B；按 F 时 A 自动从头启动，B 从当前带位播放供试听；F 期间加 S 才录入当时 A 信号，S 单按不走带。Quote 停止优先；J / L 仅移动 B。A 自动启动是白盒简化。
观察音型、卷轴、实体电平针和记忆灯点共同反馈；实际键帽随键下压复位。停止后试听损坏，重新倒带修复。
SELECT → INSPECT（双轴检查）→ BROKEN / CHANGE；完整从头转到尾 → LOAD → SEEK → HOLD_PLAY / HOLD_RECORD → REVIEW → COMPLETE

参数、判定与失败

新版录音内容8 秒、400 格、8 段合成音型，各段带细微频率变化以识别时间错位；目标 34%-66% 为空。整体时间轴须与本轮空间输入一起复验。
新版内容阈值全部格匹配比例 ≥99.5%，真实累计写格 ≥20，且 SourceVerified 为真。必须包含后续段比对；不能只因中间填上就通过。旧版94%阈值已废止。
失败反馈断带：转动受阻、带面断开，换盒；错位录制：节奏与电平不齐；误覆盖后段：真实缺音并降低匹配率；松键：机械键复位、带位停止。

实现：新输入状态以当前按键集合与左右鼠标键、滚轮增量驱动；禁止沿用单击锁存。TapeChapter 保存候选带检查区间、断点及录放时间轴，画面和声音共享数据。TapeWorld3D驱动盒带拖放、断头、轮轴、实体键帽、电平与双手；本轮须复验真实节点射线与持续键，不能沿用旧版成绩。

CHAPTER 02 / FILM胶片 · 测光、装片与复拍

先读光，再决定怎样曝光

玩法目标：测光后选择 ISO100 / 200 / 400 胶卷，按 X-700 手动相机装片逻辑的简化链操作；匹配旧照的站位、视角和曝光，最后在暗袋与冲洗罐中处理胶片。

OPEN → SELECT_FILM → LOAD → LEADER_ENGAGED → CLOSED → ADVANCED → VIEW / METER → EXPOSED → REWOUND → DARK_BAG / SPOOL → TANK → CHEMISTRY → WASH → DEVELOPED
暗袋为独立步骤：左键按住袋体＋正滚10格卷片，负滚可退；进度满才入罐。曝光帧不可变。
操作段玩家输入与反馈真实关系与判定
选卷 / 装片鼠标从三种 ISO 选卷，开后盖、装卷、引片咬合、关盖、过片；M 档。白盒自动同步 ASA。ISO 由胶卷决定；ASA 只告知测光片速，不改变胶卷感光度。换 ISO 须换卷。
独立测光鼠标操作独立测光表，读指针/刻度 EV100；本场景约为 13。先得到场景光，再用胶卷 ISO、光圈和快门选择等效曝光；不是照抄相片上的答案。
取景 / 调参拿机后WASD真实行走、右键按住环视；目镜内禁走；中心滚轮焦距、右侧快门、下侧光圈、向上退出。鼠标位置选择正在操作的实体盘；目镜保持恒亮，景深预览为正式目标，白盒仅做规则判定；自动合焦是白盒辅助。
曝光取景时左键拍摄；三要素为 ISO / 快门 / 光圈，焦距独立。成片冲洗后查看。曝光、构图、CoC与拖影分别判定；白盒像素实际应用曝光亮度，漏光以实体相纸泛白反馈；清晰度仅规则判定，等效EV不保证合格。原X-700不被描述为自动对焦机。
冲洗倒片后拖卷进不透光黑袋，左键＋滚轮卷入片轴；满进度入罐，再倒液、翻罐、水洗。袋内不裸露胶片；三药剂各轻摇再计时，错序不推进，未倒片开盖会漏光。

模型、合法组合与阈值

曝光：EV100 = log₂(N²/t) - log₂(ISO/100)，与测光值 13 比较。ISO200＋f/8＋1/250、ISO100＋f/8＋1/125 均为有效等效组合；ISO400＋更快快门也可成立。玩家未被指定只能选一卷。

构图与清晰：PhotoWorld3D使用真实透视摄像机捕获立体前中后景，纹理显示在桌上实体相纸。WASD实际移动身体，焦距改变视角；构图、曝光、CoC与拖影判定仍为可解释近似。参数和曝光姿态冻结，不能用冲洗后调参重算照片。

白盒基线参数焦距约 28-70 mm；f/2.8-f/16；快门至少覆盖 1/30-1/500；ISO100/200/400 需换卷。具体档位以新版脚本为准。
判定基线4 锚点平均误差 <21 像素，曝光误差 <0.38 EV，CoC <1.4，拖影 <3.5，未漏光；像素误差是内部投影度量，不是屏幕热点；本轮空间路径与真人输入须重新验收。
冲洗压缩显影 / 停显 / 定影 / 水洗约 3 / 0.8 / 2 / 1 秒；前三步倒液后按住实体罐拖动轻摇，水洗不需摇；不做温度浓度仿真。

失败：当前成片显示站位视差与曝光亮度，漏光用实体相纸泛白反馈；CoC和慢门拖影仅由规则及夹子失败反馈，未实现模糊图像后期。正式版须让失败原因直接可见；当前坏片可回看后重装。取景器不直接展示最终照片。正式版扩展逐张递进、完整手部与暗房演出；本轮已是立体相机、胶卷、后盖、片头、拨盘、黑袋与罐；光学和化学仍为白盒近似。

CHAPTER 03 / WRITING写作 · 手继续写，思绪继续走

同时运笔，同时走进回忆

玩法目标：右手持续写信，左手在回忆中完成被遗漏的照顾。写作让记忆能够行动，记忆中的行为让信可以继续；两侧输入必须存在真实联系。

右侧 / 右手鼠标左键按住，在纸面由左向右移动；射线落在纸面，低精度路径生成世界墨迹。到行末回到下一行起点再写。静止按住、抖动或在纸外移动不算运笔。
左侧 / 左手WASD 移动小人，靠近物件产生动作；靠近真实门洞与把手按住E扶门，携带围巾后靠近窗边人物。动作范围宽，避免精细走位。
双侧联动左侧关键进度只在有效书写窗口内增加；停笔后左侧可停留和观察，关键事件暂停。已写笔迹、已完成动作和交接进度保留。

两个透视空间同时更新：右侧为厚纸、笔尖与纸篓，左侧为门洞、家具和人物。画面并置不改变真实空间来源，不是两块平面路线图。

CHAPTER 04 / PAINTING绘画 · 注视发生的关系

看清相处中的一个动作

玩法目标：根据底稿中未完成的轮廓，观察人物动作；按住鼠标左键，在关系成立时稳定注视，逐步留下杯口与手、围巾和相接双手的笔触。

鼠标转动角色头部。松键时三维世界适度虚焦，仍能辨认轮廓与动作；按住左键约0.30秒渐清晰。画架、画布与静物同处一室，中央视线射线判断真实接点，笔触生长在画布表面。准心与帮助保持清晰。

三段观察任务

阶段底稿 / 场景线索有效条件完成后
1 围巾白盒底稿先强调围巾弯折，桌上实物有相同关系。正式版补展开、披到肩上的动作。按住左键，稳定注视围巾弯折处1.25秒；这一段为无时机限制的基础教学。围巾上色，底稿下一段杯与手的轮廓变深。
2 杯与手底稿手指与杯沿相连；空间中的手会靠近或离开杯子。按住左键，在接触窗口内稳定注视接点累计1.25秒；每 5 秒前 2.7 秒有效。杯与手落笔，底稿强调两只相接的手。
3 两手底稿两条手臂在中央断开；两侧手部相接、分开并重复。按住左键，在相接窗口注视接点累计1.25秒；每 6 秒前 3.8 秒有效。最后连线出现，等待 2.4 秒完成；以画中围巾方向引向尾声实物。

状态机与可逆反馈

白盒：Phase 0 围巾 → Phase 1 杯/手 → Phase 2 两手 → Phase 3 SETTLE → COMPLETE
各阶段：SEARCH（虚焦）→ HOLD（渐清晰）→ ACCUMULATE（关系成立＋视线稳定）→ COMMIT。

可逆反馈：按住左键时整个3D画面渐清晰，视场由64°收至58°；松开约0.25秒恢复虚焦，视场恢复原值。看错也会变清晰，未成立接触仍不落笔。松开或移开停止推进，当前累积缓慢衰减，已画笔触保留。动作重复，不因错过窗口锁死。

无文字引导与声音替代

统一顺序为“物件示范一次 → 模仿 → 变化要求推理”。3D准心靠近可交互台改变形状，E属输入提示；近景可用鼠标双键/滚轮图形。磁带五键字母和相机EV/ISO单位属于设备/输入刻度，允许存在；叙事仍不依赖文字。关键声音均有可见反馈。

可访问性正式目标：关键音频线索提供节奏光点、振幅图形或空间动作替代；颜色配合形状/纹理；可缩短聚焦时长、放宽交互半径。正式设置提供按住/切换聚焦、减弱镜头运动与虚焦强度；白盒默认持续按住左键。双手章节的单手辅助可锁存一侧动作并保留因果，须显式开启。白盒至少支持静音后完成；未实现辅助不记作已支持。

DEVELOPMENT APPENDIX / SPOILERS新版白盒答案与复验路线

用物件位置描述答案

本页只供复验，不在游戏默认展示。答案不依赖固定屏幕像素。新版本实际结果见本轮QA记录，测试捷径不替代新人引导。

旧屋WASD行走、鼠标转头，对准近处物件E进入；镜头靠近设备后进入3D记忆。Esc返回，1-5开发选章，R重置，H帮助。

1 磁带

  1. 桌前第三盒蓝灰带完整；把盒体拖入中央槽，按右键正滚约29格至末尾。左键正滚倒带，反滚反转。前两盒用于观察断头。
  2. 好带移至后方源卡座。J倒B到头，持续S＋F约8秒；也可F试听至缺口加S。观察实体键帽与电平，松键停止，Quote(')优先。

2 摄影

  1. 桌上测光表约EV100=13。ISO200卷拖入机身左仓，片头拖到右收片轴，合后盖、拨过片杆。旧照在桌后支架。
  2. 点目镜拿机，WASD走动、右键按住环视；对照前景椅背、中景围巾人物与后景窗视差。目标约本章局部X=0.55m、Z=0.40m，水平朝向，50mm。
  3. 再次点目镜进取景；中心滚轮50mm，右移设1/250，下移设f/8；回中心调焦距，上移退目镜，左键曝光。ISO100 f/8 1/125或ISO400 f/8 1/500也可。
  4. 按倒片钮正滚约8格，点击后盖打开，从左仓取已曝光卷拖进右侧黑袋；按袋口正滚约10格装片，负滚可退。
  5. 三瓶依次拖到罐口，每步拖动实体罐轻摇后等钟针3/0.8/2秒，最后水洗1秒。成片在真实夹子；坏片点夹子重装。

3 写作

右侧纸面按左键向右运笔，满行回左。左侧WASD到把手旁按住E扶门，同时写；搬箱者通过后卡稿。抓厚纸揉团，拖进右下真实纸篓。第二稿到椅子取围巾，穿门洞到窗边人物旁，同时运笔交接约0.7秒。停笔超宽限暂停；静止按住不算写。

4 绘画

松键时全景虚焦；看左侧底稿，鼠标转头并按住左键，约0.30秒变清晰。中央视线依次稳定看红围巾、手/杯口接点、两手相接处，各约1.25秒；后两步须等实际接触。松开约0.25秒渐虚焦，停止推进，已画保留；清晰本身不代表选对。

5 尾声

抓左折角拖到压痕，抓右端交叠到中央；最后按WASD任一键扶住左端，同时把结端向自己拉。两手和有厚度布形同时变化，完成后停留约2.8秒。
