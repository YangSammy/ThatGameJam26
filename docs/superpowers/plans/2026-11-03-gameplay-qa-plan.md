# 全项目 Agent 与电脑操作测试计划

> 执行方式：按任务顺序执行与记录；本文件不是自动修改玩法或启动多 agent 的授权。测试发现问题后，先保存复现证据，再在明确修复范围内处理。

**Goal:** 依据 v3 和用户后续确认方案，验证真实输入、关卡流程、存档恢复及最终玩家体验。

**Architecture:** Agent 做代码、配置、状态与日志检查；电脑原生鼠标键盘完成交互验收；独立游戏包复核 Editor 之外的行为。接口构造前置条件必须记录，不能算作该前置流程通过。

**Tech Stack:** Unity 2022.3.62f3，Built-in，现有输入、数据和存档框架；Unity MCP 与可用的电脑操作工具。

**Spec:** v3 策划案提取 output/park-blockout/v10/v3-design-extracted.txt；当前用户确认方案；docs/ParkPhotographyTasks.md；近期 B/C/D/E 接入与验证报告。docs/design.html 旧快照与实际差异须注明。

## 全局约束

- 不改变既有布局、资产 GUID、定位、人体控制和存档格式；不重置他人修改，不提交或推送。
- 使用隔离测试存档或可恢复备份；记录 Editor 每次 Play 重置配置。恢复测试必须关闭测试档自动重置，结束还原设置。
- 同一 Unity 编辑器只有一名操作执行者；其他检查不得同时改场景、Play 状态或存档。
- 不清空 Console 来证明无错误；记录前后增量。未保存场景不覆盖。
- 工具不支持可靠长按、听觉判断或截图时，记录未验证，不能用 setter 替代后宣称通过。

## 风险重点

1. 按下与松开跨输入上下文，导致粘键、误触或退出后仍运行。
2. 拖放接收、遮挡及移动镜头，导致跳位、错投、复制或丢物。
3. 稳定步骤与临时动作混淆，导致恢复后倒退或提前完成。
4. 双仓或动态材质共享状态，导致一处操作影响另一处。
5. 测试快捷键、直调接口或 Editor 行为掩盖真实玩家路径的问题。

## 用例与证据格式

每例记录：ID、版本/未提交差异、场景与分辨率、前置存档、执行方式（原生/接口/静态）、步骤、预期、实际、结果、截图或视频、日志、保存前后关键状态、缺陷编号。

结果只用 PASS / FAIL / BLOCKED / NOT RUN；已知设计差异单独标注。原生操作和接口结果分别记录。

建议报告 output/QA/2026-11-03-Gameplay/，用 cases.csv、bugs.md、summary.md、evidence/ 分别记录。每个新测试批次使用新目录。

- [ ] 记录 git 状态、Unity 版本、当前场景与未保存状态、编译与 Console 基线、测试档备份和重置配置。
- [ ] HouseScene 原生移动、转头、桌面入口、Esc、安全检视 E、复位与退出；ParkScene 进入返回。确认鼠标锁定与 UI 光标正确。
- [ ] 检查正式引用、重复 ID、Missing Script、材质、交互射线阻挡。先修阻断，再执行长流程。

## T1 录音：先完成一单，再连续三单

- [ ] TAPE-01：点桌面，拖源带入 A；试听；中途拖到无效位置松手、Esc，磁带身份与位置正确。
- [ ] TAPE-02：工作带拖准备垫；按住实际左右轴配合滚轮，覆盖整条带；壳体与轴不抢操作。检查断带不能靠封孔修复。
- [ ] TAPE-03：拉胶带头，经切刀撕断，分别贴两孔；中途松手与 Esc；重复拉取不复制贴片；单孔完成可恢复。
- [ ] TAPE-04：准备好的 B 拖离垫子并装仓，保持拖动连续、落位预览正确、镜头拉近无跳位；装带期间重复点击与 Esc 无丢带。
- [ ] TAPE-05：用当前 UI/实体按钮启动 A 与 B 录制，噪声时停 B，A 音频继续；续录不覆盖；停止 A 后回听 B；空仓/开仓不能走带。
- [ ] TAPE-06：分别提交有效结果、明显缺失关键声、全噪声结果，核对当前配置反馈；“全录可通过”与策划差异单列，不擅改容差。
- [ ] TAPE-07：三单连续完成、当前单重试、完成后回听；在单孔完成、B 暂停录制、委托完成处退出/重启恢复。
- [ ] Agent 检查共享带位、A/B 独立状态、录音样本映射、历史音源兼容及源文件引用；人工试听验证剪接结果，不用状态数值冒充可听体验。

## T2 摄影：书房到公园再返回

- [ ] PHOTO-01：四档 ISO 各完成一次装片，主体全链选一档；开盖、入仓、拉片头、扣收片轴、收紧、关盖、过片，每步验证实际命中及前置规则。
- [ ] PHOTO-02：片头拖动中取消；稳定装片后退出重进，保持已完成步骤，未完成动作安全恢复。
- [ ] PHOTO-03：原生步行至入口、桥、草地，不传送、不自动对齐；测光、调 ISO/光圈、手动调焦，固定 50 mm 不变焦。
- [ ] PHOTO-04：按任务触发偏头、转身停留、伸手回应并拍三张；验证错误焦点、曝光、构图时的真实反馈，重试不错误消耗或提前推进。
- [ ] PHOTO-05：公园不可看成片；拍一张后退出重进，保留照片、任务与容量；完成后按钮回书房，倒片、开盖、取卷，模型不重叠。
- [ ] Agent 核对三个任务引用、相机设置、真实图片文件与顺序、快门提交时机、重复提交保护及存档恢复。正式人物动画不足单独记为内容缺口。

## T6 系统与发布回归

- [ ] 不用 1–6 或补片快捷键，从新测试档串行完成五天；每日至少一次退出与恢复。
- [ ] 独立 Windows 游戏包重复核心流程；覆盖目标窗口与全屏、至少两种分辨率、30/60 FPS 条件；实际测量而非推断性能。
- [ ] 隔离测试目录中覆盖缺失/损坏存档、受控写入失败；不得改真实用户档或以占满磁盘制造失败。
- [ ] 修复后复测失败用例与相邻路径：输入改动回归各模式，存档改动回归各章，拖放改动回归磁带/片头/暗室/钥匙。

## 缺陷等级与退出条件

- S0：崩溃、存档损坏或数据永久丢失。
- S1：正常流程卡死、关键物品丢失、核心输入失效、不能推进。
- S2：可绕过但严重影响操作、反馈误导或玩法目标被绕过。
- S3：轻微显示、声音、对齐问题。
- 发布验收要求：S0/S1 清零；正常主线原生操作通过；关键取消与恢复通过；S2 有明确处理决定；静态、接口、原生与未验证结果分列。
- 熟悉实现的 agent 无法代表首次玩家。另安排未读操作文档的玩家测试可理解性，记录首次卡点、误操作和提示依赖；本计划不虚构此类测试已完成。
