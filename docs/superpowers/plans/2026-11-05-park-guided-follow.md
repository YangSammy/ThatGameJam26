# 公园自动跟随实施方案

用户已选择并授权实施：路途完全自动跟随，三处拍摄区受限微调，拍完收起相机再前进。

## 行为与架构
- 新增 ParkPhotoPrototype.GuidedWalk partial，负责玩家路线、停靠、微调与等待收机；ParkCompanion 保留已有角色导航和演出，新增 TravelPaused 仅停止赶路，不阻断到点后的回眸/伸手。
- 玩家沿现有路点折线行走，不直接追少女。跟随约2.5m，速度平滑追随；最后停靠到当前referenceView脚位，不自动转头。不越过当前任务的有效路线段。
- 初次未装片不出发；相机/测光操作时两人停步；暂停失焦停步。拍摄区只有停靠完成才开放WASD，默认横纵各1.1m椭圆；桥边横向.55m、前后1m，保留碰撞和重力。
- 快门成功后保持当前节点等待，收机才InitializeBridge切换下一节点并建立下一段路线；第三张直接现有暗室返回。暂停收机不误触发出发，恢复后继续。
- Q呼唤、R重走从正常摄影输入移除；测光功能保留。无新增包、无场景定位修改、无存档结构修改；退出仍恢复当前未完成节点。
