# 摄影流程恢复修复

依据用户已批准的风险修复请求，保持现有装片、拍摄、冲洗流程。

1. PhotoWorld3D：倒片累计；仅摄影使用短距离遮挡拾取，不能透过帘子和家具投放。拖拽取消不提交。
2. PhotoWorld3D.Recovery：按阶段恢复安全位置、显示当前步骤/失败原因；失败可原地重拍，避免重复冲洗才知道基础错误。
3. PhotoProgressStore：版本化单文件保存状态和照片，临时写入后原子替换并保留备份。读取验证，损坏文件不静默覆盖。只保存当前共享书房摄影，不影响其他关卡。
4. 拍摄画面应用与判定相同的模糊指标，照片冻结后不随后续场景改变。实际取景器视角与成像保持相同宽高比。
5. 验证：倒片分次、退出/重进各阶段、遮挡与距离、保存重载/备份回退、真实 Stop/Play 恢复照片、失败重拍和完整冲洗。测试使用隔离存档并还原现场，运行结束退出 Play。
