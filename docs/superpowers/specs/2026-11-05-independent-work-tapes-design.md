# 三份委托使用三盘独立好带

用户已明确要求设计并开始实施：选新带→检查双轴→封两孔→录音→验收成功→该带进入成品格→下一份另选新带。

采用原系统扩展：五盘工作带（现有两坏一好，加两好），三盘源带保持原身份。独立物件ID保存扫描、双孔、位置以及归档委托。保持当前F/J/L/停止控制A、S切换B、双键转壳、准备垫与贴上即封孔。

选择：扩展现有Candidate/ItemSaveRecord和场景实例；不创建第二库存系统，不把同一物件复位伪装新带。提交时先保存真实PCM和章节事务，成功后将同一工作带移入对应成品格，不生成替身。失败保持当前工作带和准备状态。成品不可再次准备或录音。预先检查过的其他带不清零。

PCM继续按委托保存，开始录音后绑定当前委托的工作带；退带重装仍绑定原带，不能换一盘空带继承录音。重试清当前录音但不清检查/封孔，允许在明确重试后选其他未归档带。

兼容：版本8及更早的三个候选记录迁移为五个独立物件。保留现有三个ID与未提交录音；已交付委托映射到新增好带（需要时再用原好带），当前未完成原好带不被归档占用。旧PCM不改写。完成状态、顺序、成品唯一性严格校验。

场景增加两盘克隆自当前好带的可检查实例、独立收纳/桌面落点及3个成品锚点。保持原资源GUID和已有定位；仅调整收纳槽必要布局以避免遮挡。原装饰成品隐藏，改为真实归档带。

验收：模型五盘/三份不同身份；检查状态跨提交和重启保留；失败不前进；归档不能再次录；旧存档迁移；新场景引用/命中；三份真实映射提交与读档。保留当前共享场景/存档的可恢复副本，不提交或推送。
