# 留在手里的事

**0.3.1 全 3D 白盒**，Unity 2022.3.62f3 原生 C#。从第一人称旧屋进入五个真正的三维解谜空间：磁带、胶片摄影与冲洗、双线写作、聚焦绘画、围巾尾声。所有解谜物件均为 Mesh / Collider / 射线交互；不再使用二维工作台界面。场景、人物、手和音效均为几何或程序占位。

参考《艾迪芬奇的记忆》的物件触发回忆、第一人称身体动作、逐章变化的输入方式，以及 Lewis 章节的双手注意力分配。进入物件时镜头靠近，再溶入三维回忆；当前是功能白盒，未复刻原作场景、人物或美术资产。

## 运行

场景编辑：收音机 `Radio case` 的位置、旋转、缩放由场景保留，动画仅控制内部部件。`Anchors / Spawn_Player` 控制出生位置、朝向和视野；`View_RadioOperation` 控制磁带关卡镜头的位置、朝向和视野。直接在编辑模式调整定位物体即可。

- **当前整合入口：`Assets/Scenes/HouseScene.unity`。** 五个操作点同处一间屋内，WASD 行走、鼠标环视，走近并对准物件后左键进入；镜头过渡结束、松开交互按键后开始操作。Esc 退出关卡并恢复进入前的位置与朝向，H 查看帮助。退出会停止操作并保留关卡进度；HouseScene 摄影另有跨次自动存档，其他关卡仍仅保留本次运行进度。
- HouseScene 的磁带关卡现使用书桌上的新收音机与三盒导入磁带。左键进入操作视角；按住左键拿起磁带，拖到卡槽后松手装入。槽外松手留在手中；指向轮轴按住左键并滚动检查，按住外壳可重新拖动，右键放回。发现断头后换带，已发现断头的磁带不能装入。沿用现有装带动画与音频。完整检查好带后装入播放即完成本阶段。E 安全检视、双键转整体、左键动部件、F 翻面、滚轮远近仍独立且不修改真实进度。
- Inspector 统一入口：`Player / Camera_Player → Safe Inspection`（面板标题“统一检视配置”）。中文分组包含检视距离与构图、检视动作、实际磁带手持位置/角度/速度；参数名称悬停显示说明。也可用菜单 `Tools → 检视 → 选择统一检视配置` 定位。展开“选择要微调的物品”可跳转到物品的检视组件，物品侧仅显示“初始朝向微调”和“观察中心偏移”。所有已接入检视的物品共用 55° 检视视野和 0.38 米展示尺寸；每次进入自动测量可见模型的中心与尺寸，中心偏移默认零。退出恢复进入前视野。录音机已校正正面朝向与机壳旋转中心，与磁带一样在眼前展示，共用距离和尺寸，支持双键拖动旋转、F 翻面、滚轮远近；真实设备留在场景中，退出恢复原状。旧手持设置自动一次性迁移；关卡操作镜头继续调整 `Anchors` 定位物体。在编辑模式修改并保存。
- 屋壳、新收音机、磁带及检视展示物均保存到场景；其他四关沿用现有生成器。主控制器直接引用玩家摄像机、第一人称手和当前收音机；旧磁带场景、旧双卡座设备、控制器及跳转兼容代码已移除。修改脚本触发运行中重载后需要停止并重新 Play，临时进度不跨脚本重载保存。

- Windows 运行包解压后，直接运行 `MemoryGame.exe`，请保留同目录的 `MemoryGame_Data`、`MonoBleedingEdge` 与 DLL。工作目录中的已构建程序位于 `Build/MemoryGame.exe`。
- 源码包不包含已构建程序；用下面的 Unity 流程打开，或运行 `BuildUnity.ps1` 重新构建。
- 从 Unity Hub 添加本目录，用 Unity **2022.3 LTS** 打开 `Assets/Scenes/HouseScene.unity`，按 Play。交付版本使用本机的 **2022.3.62f3**。
- 离线编辑可运行 `OpenUnity.ps1`，它使用官方 `-noUpm` 参数关闭本原型不需要的联网包管理。项目没有外部资源包依赖。
- 策划案：`docs/design.html`；打印版：`docs/留在手里的事_落地策划案.pdf`。最后三页含完整操作表、验证答案与白盒范围。

## 公共操作

HouseScene 中 WASD 行走，鼠标环视；对准近处物件按左键进入，Esc 返回进入前的位置。H 显示操作说明。摄影进度与照片自动保存到本地；其他关卡进度只在本次运行中保留。

游戏默认不显示叙事文字。H 说明和调试选章仅服务玩法验证；设备上的 ISO、快门与光圈刻度属于设备信息。OnGUI 只绘制准星、可选开发说明和转场遮罩，章节不调用旧状态模型的 Draw。

## 章节操作

1. **磁带**：把候选带拖入机芯。按住左键滚轮转左轴（正滚倒带）；按住右键滚轮转右轴（正滚放带），反滚反转。断带必须换盒，全程检查无断点的一盒后进入录放。机身五键从左至右为 **S 录音、F 播放、J 倒带、L 快进、' 停止**，持续按住才保持。按住 S+F 录制，松手停；目标带偏移会造成真实错录。白盒素材A随F从头启动，目标B从当前带位启动。
2. **摄影**：三种 ISO 胶卷拖进相机左仓，拖片头至右轴、合后盖、拨过片杆。点击桌上实体测光表/参考照片会靠近观察，再点击返回。第一次点目镜拿起相机，WASD 找拍摄位置、按住右键环视；再点目镜取景。取景后纯鼠标：中心滚轮变焦，向右切快门，向下切光圈，向上退出，回中心重新变焦；左键曝光。按住倒片钮正滚8格回卷，开后盖取出胶卷拖进黑袋，左键滚轮10格绕片。按1、2、3顺序把药瓶拖到罐口，每次按住罐身拖动轻摇后等待钟针，最后点水龙头水洗。照片来自实际三维场景，只在显影后呈现于实体相纸上。
3. **写作**：右手按鼠标真实向右运笔，行满回左边继续；左手 WASD 在回忆中行走。门边按住 E 扶门，同时书写。卡稿把纸拖入篓，再拾围巾、走至窗边持续书写交付。静止按鼠标不算写。
4. **绘画**：鼠标实际转动第一人称视线，松开左键时全景虚焦，**按住左键约0.30秒恢复清晰**；松开约0.25秒恢复虚焦。参照绘画本底稿（独立旧场景仍使用画架），按住左键并让中央准星稳定看向围巾、杯口与手的接触、两手相接；每笔约1.25秒，后两笔要等动作到位。松开或移开停止当前聚焦推进，已完成笔触保留。滤镜只影响绘画三维画面，准星/开发说明保持清晰，退出立即移除。
5. **尾声**：拖围巾角抚平、拖另一端交叠；最后按住 WASD 任一方向键扶住左端，同时用鼠标拖右端收紧。

## 摄影验证答案

HouseScene 使用书桌、大窗和挂衣架区域作为构图目标：世界站位 X=-0.8、Z=0.2，Yaw=0°，50mm、ISO200、f/8、1/250。倒片后持胶卷移动到书桌右侧，左键拉开帘子，进入暗室冲洗；三瓶药水从柜前通道取用。

摄影回忆空间的目标站位（相对该空间原点）：X=0.55、Z=0.4，朝向Yaw=0，50mm，ISO200、f/8、1/250；ISO100、f/8、1/125也是合法等效曝光。实际透视摄像机拍摄该三维空间，曝光后冻结纹理；构图、曝光、景深和拖影阈值用近似模型验收，当前没有完整光学后处理。白盒省略独立手动合焦，采用中心目标距离；X-700原机是手动对焦。

## 工程结构与复验

- `Assets/Scripts/Core/WBMain.cs`：第一人称探索、镜头转场、原生三维输入路由。
- `WorldChapter3D.cs`：实体物件、Collider 射线拾取、世界平面拖动、三维笔触与设备刻度。
- `HouseRadioDeck.cs` / `PhotoWorld3D.cs` / `WritingWorld3D.cs` / `PaintingWorld3D.cs` / `EndingWorld3D.cs`：五章三维交互、相机与表现。磁带辨认状态由 `TapeInspectionState.cs` 管理。
- `PaintingDefocus.cs` 与 `Resources/PaintingDefocus.shader`：绘画相机虚焦后处理，按住/松开渐变；使用内置渲染管线，无外部后处理包。
- `RoomWorld.cs`：程序生成旧屋、移动与桌面交互。
- `Chapter.cs` 与旧 `*Chapter.cs`：共享输入和规则状态机，旧 Draw 不用于运行画面。
- `Assets/Editor/Build/GameBuild.cs`：构建 HouseScene 和 ParkScene。菜单 `Tools/Build/Build Windows Player`。
- `BuildUnity.ps1`：批量构建 Windows Player；玩法回归由 `HouseGameplayChecks` 单独执行。

正式设计与当前白盒差异、资源估算、开发里程碑、验收表和公开参考在策划案中说明。当前已实现三维解谜与几何手部代理；没有正式剧情资产、完整手部骨骼动画、完整光学渲染、全游戏存档或布料物理仿真。

## 第一人称操作手

HouseScene 的玩家手模型由 `Player/Camera_Player` 上的 `FirstPersonHands` 管理，主房间直接引用玩家摄像机、手部和当前收音机。其余关卡的玩家手作为隐藏动作目标，退出关卡后恢复探索姿态。绘画中的人物接触手仍属于观察对象。玩家手使用独立渲染层，不参与拾取，也不会进入胶片成像。当前为几何手部，未加入骨骼动画。

## 单屋书房布局

HouseScene 为约 7.6 × 8.8 米的书房。进门正前方是一张共用书桌，背后是大窗。桌面左侧放收音机和磁带，中间放书写纸笔，右侧放绘画本和相机。围巾挂在左侧落地挂衣架上。书桌右侧的帘子隔出小暗室，内设冲洗台；左键点击帘子开合，关闭时阻挡通行。

走近并用屏幕中心对准物件，左键点击后镜头先靠近，短暂淡黑切换至对应操作视角。松开进入时按住的键鼠后开始操作；Esc 可在转场中或关卡内返回原位置。收音机和磁带共同进入现有磁带关卡，未新增独立收音机玩法。围巾入口在衣架上，进入后在书桌上完成原有折叠操作。

房间、家具、六个入口物件和磁带操作道具保存在场景 Hierarchy。探索时只显示日常入口物件；进入关卡后显示对应操作道具，退出恢复入口物件。其他四关的操作道具仍在启动时生成一次并保留进度，未全部改为编辑期资产。暗室冲洗用品在运行时保持可见。玩家手仍归第一人称相机管理。当前为几何白盒，尚无正式模型、布料效果和手部动画。

本轮验证：`QA/shared-house-checks.json`（72 项）、`QA/lived-in-room-checks.json`（55 项）、`QA/tape-closeview-checks.json`（28 项）；另外检查六个入口的真实射线点选、帘子开合和暗室通行。画面：`QA/study-desk-overview.png`。验证通过 Unity 交互方法与 Collider 自动执行，未作真人键鼠全程试玩，也未更新 Windows 构建。布局修改前备份在 `QA/Backups/before-study-desk/`。

## 摄影退出与恢复

摄影自动保存装片阶段、曝光参数与照片、倒片/暗袋进度、药液次序、冲洗剩余时间和完成状态。Esc 取消手中拖拽，装片/拍照阶段回桌前，暗袋/冲洗阶段恢复至暗室安全位置并打开帘子；离开期间计时暂停。倒片松手可继续。按阶段保存，并每半秒检查变化，退出时再次保存；强制终止可能丢失最后约半秒操作。

默认存档位于 Application.persistentDataPath/study-photo-v1.json，单文件包含 PNG 照片，原子替换并保留 .bak。主文件损坏时恢复备份并保留损坏文件；两份均损坏时显示提示且不覆盖原文件。此版本仅支持共享书房摄影，不迁移旧的内存进度。

摄影拾取距离限制为 2.5 米，帘子和家具阻挡交互。先打开帘子再持胶卷进入暗室。底部显示下一步；拍摄后可提前得知构图、曝光、模糊或漏光问题，并点击“重新装卷拍摄”放弃本次曝光。显影仍决定是否完成。照片加入近似散焦/拖影表现，未实现完整光学模拟。

验证记录：QA/photo-recovery-checks.txt（47 项专项）、QA/photo-restart-checks.txt（实际停止/重启与 PNG 一致性）、QA/lived-in-room-checks.json（55 项原有流程）。

## 安全物件检视

HouseScene 探索时走近并对准收音机、磁带、相机、纸笔、绘画本或围巾，按 **E** 检视。原有左键进入关卡保留。新收音机磁带关卡内，把鼠标指向磁带、轮轴、录音机外壳或按键，按 E 检视；先松开正在操作的键鼠，并暂停播放。E 是唯一的安全检视入口。左键拿取是实际玩法操作：按住拖动，卡槽上松手装带，槽外松手留在手中；不会进入安全检视。安全检视关闭后恢复进入前状态。

- **观察外观**：左右键同时按住拖动旋转，F 翻面，滚轮远近。收音机和录音机原地靠近，不悬空翻转。
- **检查结构**：无需切换模式，左键拖动卷轴、旋钮、后盖、纸页或围巾短端。按钮/笔帽按住移动，松手回弹。铰链与旋钮有行程限制和短触碰音。指向可见部件时淡淡提亮，并显示名称和操作提示；遮挡后的部件不能隔空选中。
- **双键判定**：约 80 毫秒组合窗口内，左右任意顺序形成双键都只旋转整体。已开始的部件操作不会因补按右键变成旋转。旋转时松开任何一键就停止，必须两键都松开后才能开始新动作。
- **重置检视**：点击画面左侧按钮或按 R，平滑恢复本次检视开始时的角度、距离及全部展示部件状态，并取消当前拖动；不重置真实物件、磁带选择、关卡进度或存档。
- **放回**：Esc 或底部按钮，右键不再退出。只退出检视；在磁带关卡内回到操作台，再按 Esc 才离开关卡。恢复进入时的视角与鼠标状态，等待所有按键松开后再交还操作。
- 部件只驱动展示模型，不拍照、不倒带、不播放、不改进度或存档。失焦自动关闭；禁止从尚未结束的磁带鼠标操作进入检视。

模型预先保存在场景根节点 **Safe inspection - authored display models**，不在进入检视时生成。每个 Subject 记录原件、展示件、部件与映射；相机下有独立检视 Camera/Light/AudioSource。打开时同步外观、颜色及姿态，原件仅隐藏渲染，真实碰撞与变换不变。书房入口相机增加可打开的空胶片仓示意，磁带/纸笔/绘画本/围巾增加磨损或修补示例；仍为白盒资产，尚无正式贴图、布料变形与手部抓握动画。

当前覆盖书房探索物件和磁带关卡；摄影、书写、绘画、围巾关卡进行中不新增检视入口。新增资产在 Assets/SafeInspectionAssets，编辑器安装工具 SafeInspectionBuild 不重建房间。验证与限制见 QA/safe-inspection-validation.md。


HouseScene 鼠标恢复：运行中的探索状态隐藏并锁定鼠标；切回游戏后按当前状态恢复。主房间 Esc 不再切换自由鼠标。检视与需要指针的关卡仍显示鼠标，退出重新收起。失焦不捕获桌面鼠标；编辑模式保留编辑器鼠标。验证见 QA/house-cursor-fix.md。

## 接入／更新可检视物品

在 Hierarchy 选中物品根节点，打开 `Tools → 检视 → 接入或更新选中物品`。窗口会找到同一场景的统一检视组件和原检视记录。

1. **新增摆件**：填写显示名称；只观察外观可不添加部件，点击“接入检视并自动注册”，然后保存场景。工具生成展示副本、注册引用、建立 E 检视入口和必要拾取区域。
2. **替换内部模型**：保留原玩法根节点，替换美术子节点，再选原根节点打开工具。核对部件匹配，点击“更新检视副本并重新绑定”，保存场景。
3. **整个根节点被替换**：选新根节点，把展示库中原有的 `Inspect - ...` 物体拖入“原检视记录”。工具保留原检视记录身份和微调参数，重新绑定到新模型；关卡玩法专用引用仍需另行维护。
4. **可操作部件**：在窗口指定对应原模型节点、名称、翻盖/旋钮/按钮类型、运动轴和范围。更新会保留已有设置，优先按原对象或唯一同名路径匹配；缺失项必须重新指定或明确勾选移除。轴心偏移与行程使用父节点局部单位，额外命中半径使用米。

现有交互碰撞体优先复用；独立新摆件只有 E 检视，不自动增加左键关卡入口。更新不会改动关卡操作镜头。支持 Ctrl+Z；请手动保存场景。已经接入的物品也可从“物品检视入口”组件上的按钮再次打开工具。

当前支持普通网格模型和 TextMesh 文字；骨骼蒙皮、粒子、线条等会在接入前明确提示暂不支持。新模型使用 -Z 正面、+Y 向上，现有物品类型沿用集中朝向规则。按快速迭代要求，本轮未运行 Play 或测试。
